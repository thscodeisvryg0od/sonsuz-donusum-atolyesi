# Sonsuz Dönüşüm Atölyesi

Bu proje, yapay zeka yeteneklerini sergileyen, kullanıcı etkileşimine göre anlık olarak değişen dinamik bir web sitesidir. Statik içerik yerine, ziyaretçinin yazdığı her kelimeye ve hareketine tepki veren canlı bir organizma gibi tasarlanmıştır.

## Özellikler
- **Generatif Sanat:** Kullanıcı girdisine göre anlık görsel dönüşüm.
- **Dinamik Tema:** Kelime analizi ile renk ve atmosfer değişimi.
- **İnteraktif Parçacıklar:** Fare hareketlerine duyarlı canvas animasyonları.
- **Modern Mimari:** Modüler HTML, CSS ve JS yapısı.

## Kurulum
1. Projeyi zip olarak indirin veya repo'yu clone edin.
2. `index.html` dosyasını tarayıcınızda açın.
3. Bir kelime yazın veya "Sanatçı Modunu Aç" butonuna tıklayın.

## Teknolojiler
- HTML5 Canvas
- CSS3 Animations
- Vanilla JavaScript (ES6+)
